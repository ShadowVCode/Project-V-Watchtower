# Contributing

Project V Watchtower is experimental and should prioritize correctness, traceability, security boundaries, and honest user warnings over rapid feature accumulation.

## Good contributions

- Reproducible bug fixes
- Accessibility improvements
- Documentation corrections
- Test coverage
- Performance optimization
- Safer provider adapters
- Clear source attribution
- Better error handling
- Reduced permission scope
- Security hardening
- Local-first workflow improvements

## Pull-request expectations

A contribution should explain:

- The problem
- The change
- Security and privacy impact
- Data-provider impact
- Local-storage or migration impact
- How it was tested
- Any new dependency
- Any new permission, endpoint, or secret

## Dependencies

Do not add a dependency merely for convenience. Explain why the dependency is necessary, its license, maintenance status, browser/Tauri compatibility, and security impact.

## AI-generated code

AI assistance does not remove the contributor's responsibility to understand, test, license, and review the submitted code.

## License

Contributions must be compatible with AGPL-3.0-only and applicable upstream licensing.
