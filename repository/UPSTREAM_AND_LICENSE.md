# Upstream, Attribution, and License Notice

## License

Project V Watchtower's package metadata identifies the software as:

`AGPL-3.0-only`

The full license text must remain available in the repository and corresponding source archive.

## Corresponding source

Every public binary release should provide the corresponding source used to build that binary.

This release workflow attaches:

`Project-V-Watchtower-1.0.0-Source.zip`

The source archive must be reviewed before publication to ensure that:

- It corresponds to the released binaries.
- Required build scripts and source files are present.
- The AGPL license is included.
- Applicable upstream notices remain present.
- Secrets and private local data are excluded.
- Third-party redistribution obligations are respected.

This document is practical release guidance, not legal advice.

## Upstream relationship

Project V Watchtower is a modified fork based on upstream World Monitor-derived code and services.

It must not be described as:

- The official World Monitor service
- An official upstream release
- A government system
- A product endorsed by external data providers
- A product endorsed by GitHub, Microsoft, Tauri, Ollama, MapLibre, or other dependencies

Preserve upstream copyright, attribution, source references, and license notices where required.

## Data providers and trademarks

A software license does not automatically grant rights to redistribute:

- Provider data
- Logos
- trademarks
- map imagery
- camera feeds
- screenshots
- bundled datasets
- proprietary icons
- third-party documentation

Review each provider's terms and attribution requirements before public distribution.

## GitHub-generated source archives

GitHub automatically generates source ZIP and tar archives from the repository tag.

Because this release repository is documentation-focused, those automatic archives are not the Project V application source. The specifically named corresponding-source release asset must remain attached and clearly described.
