# Roadmap

## Release hardening

- Independent security review
- Authenticode signing
- Permanent updater signing identity
- HTTPS updater manifests
- Reproducible release documentation
- Dependency and third-party notice review
- Provider-term and attribution review

## Performance

- Reduce large frontend chunks
- Improve route- and workspace-level code splitting
- Load heavyweight map, PDF, and analytic components only when needed
- Measure startup, memory, and long-session behavior

## Reliability

- Broader Windows hardware testing
- Installer upgrade and uninstall testing
- Backup and restore compatibility tests
- Provider failure simulations
- Offline and restricted-network testing
- Crash-recovery validation

## Research and provenance

- Stronger source provenance records
- Better citation export
- Additional contradiction and timeline tools
- Clear confidence and uncertainty fields
- Safer sharing and redaction workflows

## Optional future services

- Portable edition
- Self-hosted Project V gateway
- Signed connector catalog
- Mobile Companion
- Synology-hosted service
- Expanded reviewed plugin packs

No roadmap item is a promise or guaranteed delivery date.
